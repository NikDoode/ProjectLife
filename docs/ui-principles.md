Интерфейс строится вокруг внимания пользователя, а не вокруг полноты отображения данных.
Пространство должно оставаться свободным; пустота является частью интерфейса.
По умолчанию показывается только активная часть системы; архив и замороженные элементы скрыты.
Каждый компонент отвечает только за свой уровень внимания.
Детализация раскрывается постепенно: объект → краткая карточка → полное описание.
