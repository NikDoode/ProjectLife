## Этап 007 — Пространственное редактирование

- [x] Свободное перемещение узлов
- [x] Сохранение и восстановление координат
- [x] Автоматическое размещение новых объектов
- [x] Сброс расположения
- [x] Три фиксированных размера узлов: 56, 110 и 170 px
- [x] Предустановленные цвета узлов
- [x] Пять готовых тем пространства
- [x] Переключение сетки и линий связей
- [x] Переключение выполненных и архивных объектов
- [x] Настройки отображения объекта в Inspector
- [x] Отдельное хранение предметных данных и настроек представления

Текущие ограничения:

- настройки представления хранятся локально в браузере;
- статус `cancelled` используется как признак архивного объекта;
- произвольное изменение размеров узлов не реализуется.

## Этап 007.1 — Полировка взаимодействия

- [x] Разделение обычного клика и перетаскивания узла
- [x] Inspector не открывается после drag-жеста
- [x] Следующий обычный клик после перемещения снова выбирает объект
- [x] Масштабирование колесом мыши и жестом тачпада
- [x] Масштабирование относительно положения курсора
- [x] Независимость сохранённых координат от текущего масштаба

Масштаб является временным состоянием Spatial View и не сохраняется между запусками.

## Этап 008 — Несколько рабочих пространств

- [x] Системное пространство «Общее» со всеми объектами
- [x] Создание и переключение пользовательских пространств
- [x] Независимые координаты, размеры и цвета узлов в каждом пространстве
- [x] Правила отображения: объект, непосредственные дети, всё поддерево
- [x] Автоматическое включение новых потомков по правилам
- [x] Добавление существующего объекта из «Общего»
- [x] Создание общего `Item` из пользовательского пространства
- [x] Автоматическое закрепление созданного объекта отдельным правилом при необходимости
- [x] Направленные иерархические связи родитель → дочерний объект
- [x] Изменение правила присутствия выбранного объекта через Inspector

Идентичность рабочих пространств сохраняется в backend. Их правила, placements и настройки отображения на текущем однопользовательском этапе остаются локальными в браузере. Удаление и переименование пространств в интерфейсе пока не реализованы.

- [x] Вторичное появление глобальных дополнительных детей в Tree View
- [x] Настройки видимости категорий связей
- [x] Автоматические backend-тесты связей
